# 2026-11-05 (1) — The native view takes the page's measures

- The page is the oracle: `markdown-look-compare` draws a file both ways and prints similarity, ink bands and (new) table column rules and the page's boxes. Spacing, line boxes, code pills, link
  underlines, lists, quotes, alerts, tasks, tables, footnotes, diagrams and pies were each brought to within about a point.
- Tables: the HTML's `TableLayout` is the native view's too; columns share the room as the browser shares it (checked at 420, 700 and 1000 pt, with and without outline, column lines, scrolling).
  No scroll bar, no bounce. New settings: scroll a table across the window from the text's edge; align the text to the leading edge.
- Selection across the whole document, by drag, double click (word), triple click (paragraph) and select all; the copy is the Markdown of whole rows. Tested by events sent to a window that never
  comes to the front.
- Backdrop: material with a thickness, Liquid Glass (regular or clear), clear, solid. The lab is a toolbar toggle in every document window.
- Fonts per style with OpenType features, and serif / mixed presets, in the page, the native view and Settings.
- Not done: other engines in the benchmark (owner's note), the table header's glyph weight, Gantt and mind-map native drawing, macOS 26 runtime.
